# TheWild

Minecraft 1.20.1 Forge mod combining realistic hunting, fishing and survival.

Inspired by hunting and fishing simulators, while keeping Minecraft's open-world sandbox identity.

## Current development status

**Prototype gameplay foundation implemented.**

### Wildlife prototype
- Red deer
- Wild boar
- Red fox
- Gray wolf

The first animals have:
- Natural biome-aware spawning
- Individual randomized body scale
- Individual randomized weight
- Ground movement AI
- Panic behaviour
- Player avoidance/stalking distance foundation
- Random wandering
- Look-at and idle behaviour
- Breed-offspring hooks for future population systems
- Temporary animated vanilla quadruped renderers
- Spawn eggs for testing

### Technical foundation
- Minecraft 1.20.1
- Forge 47.4.23
- Java 17
- Data-driven species definitions
- GitHub Actions Gradle build pipeline

The temporary models/textures are intentionally placeholders. The next art phase will replace them with custom Blockbench models, AI-assisted references, realistic textures and dedicated animations.
