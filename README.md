# TheWild

Minecraft 1.20.1 Forge mod combining realistic hunting, fishing and survival.

Inspired by hunting and fishing simulators, while keeping Minecraft's open-world sandbox identity.

## Status

Pre-production / specification phase.

## Target

- Minecraft 1.20.1
- Forge
- Global real-world fauna
- Vanilla mobs coexist with TheWild fauna
- Realistic-styled models and equipment
- Natural biome-based distribution
- Hunting, fishing, survival, tracking and trophies
